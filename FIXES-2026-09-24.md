# Nirmal Karaoke v24

Core rebuild after v23 regression.

- Audience program audio uses LiveKit-managed `webAudioMix` with an interactive 48 kHz AudioContext instead of a hand-built MediaStreamTrack receive graph.
- Remote host audio is attached through LiveKit’s supported `RemoteAudioTrack.attach()` path and a single dedicated `<audio>` sink, with explicit low-latency jitter target and adaptive protection only after measured network degradation.
- Host program track is published as a normal audio `Microphone` source with 128 kbps stereo Opus, RED enabled, DTX disabled, high priority, and forceStereo. Host identity distinguishes program audio from audience mics.
- Audience LRC now supports explicit state requests and accepts `INIT_LYRICS`, `SYNC_TIME`, and `STATE_SNAPSHOT` without dropping them when the sender metadata is absent.
- Audience lyric clock compensates for the age of the received timestamp and runs locally with requestAnimationFrame.
- Guest voice presets have a dedicated apply function, a mobile-safe button UI, a Normal preset initialization, and a safe waveshaper path.
- Audience video is shed before audio when network health degrades.
